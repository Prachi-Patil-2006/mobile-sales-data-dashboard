# mobile-sales-data-dashboard
Mobile Sales Data Dashboard | Interactive sales analytics and visualization of revenue, quantity sold, transactions, payment methods, customer ratings, and mobile brand performance.
📱 Mobile Sales Data Dashboard
📊 Project Overview

The Mobile Sales Data Dashboard is an interactive data visualization project designed to analyze mobile sales performance across different brands, mobile models, payment methods, cities, months, and customer ratings.

The dashboard provides a comprehensive overview of key sales metrics and helps identify trends, compare product performance, and understand customer purchasing behavior.

✨ Key Features
Total Sales: Track overall revenue generated from mobile sales.
Total Quantity: Monitor the total number of units sold.
Transactions: Analyze the total number of sales transactions.
Average Sales: View the average sales metric displayed on the dashboard.
Monthly Sales Trends: Compare sales performance across all 12 months.
City-Wise Analysis: Visualize sales distribution across cities.
Mobile Model Comparison: Compare sales across different mobile models.
Payment Method Analysis: Understand transactions by credit card, UPI, debit card, and cash.
Customer Ratings: Analyze sales distribution by customer ratings.
Day-Wise Sales: Identify sales patterns across different days of the week.
Interactive Filters: Filter results by mobile model, payment method, brand, and day name.
